# Jorawar Dham - Internationalization (i18n) Architecture

## 1. Supported Locales

- **Hindi (`hi`)**: Devanagari script, default spiritual language of Rajasthan.
- **English (`en`)**: International and inter-state devotee access language.

---

## 2. Locale-Aware Routing Pattern

The platform uses Next.js App Router dynamic segment routing:

```
app/
  [locale]/
    layout.tsx       -> Injects <html lang="hi|en">, fonts, and global chrome
    page.tsx         -> Root home view for the given locale (/hi, /en)
    about/page.tsx   -> /hi/about, /en/about
    history/page.tsx -> /hi/history, /en/history
    dham/page.tsx    -> /hi/dham, /en/dham
    darshan/page.tsx -> /hi/darshan, /en/darshan
    seva/page.tsx    -> /hi/seva, /en/seva
    events/page.tsx  -> /hi/events, /en/events
    gallery/page.tsx -> /hi/gallery, /en/gallery
    contact/page.tsx -> /hi/contact, /en/contact
```

### Route Preservation on Language Switch
The `LanguageSwitcher` component extracts the active pathname, replaces the leading locale slug (`/hi` -> `/en` or `/en` -> `/hi`), preserves subpaths and query parameters, and sets the `app_locale` cookie for future visits.

## 3. Dual-Tier Translation Model

### Tier 1: Static UI Strings (Dictionary Files)
Static headers, form labels, button texts, navigation items, and fixed notices live in:
- `messages/hi/common.json`
- `messages/en/common.json`

Accessed via helper:
```ts
import { getDictionary, Locale } from "@/lib/utils/i18n";
const dict = getDictionary(locale);
```

### Tier 2: Dynamic Database Content
Entities requiring editorial translation (Notices, Events, Services, FAQs, Page Sections, SEO) use normalized dual-language columns in PostgreSQL:
- `titleHi`, `titleEn`
- `subtitleHi`, `subtitleEn`
- `descriptionHi`, `descriptionEn`
- `bodyHi`, `bodyEn`
- `timingHi`, `timingEn`

Accessed via helper:
```ts
import { localize } from "@/lib/utils/i18n";

// Returns item.titleHi if locale === 'hi' (or falls back to titleEn)
const title = localize(notice, locale, "title");
```

## 4. Typography & Devanagari Rendering

- **Devanagari Font**: *Noto Sans Devanagari* / *Mukta* / *Rozha One* loaded via Google Fonts.
- **Line Heights**: Increased line height (`leading-relaxed` or `leading-loose`) applied automatically to Devanagari text blocks to prevent clipping of upper and lower matras (मात्राएँ) and conjunct consonants (संयुक्ताक्षर).
- **SEO & Alternate Links**: Renders `rel="alternate"` `hreflang="hi"` and `hreflang="en"` tags in metadata for search engine indexing.
